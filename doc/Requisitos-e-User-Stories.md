# Priorização dos Requisitos e User Stories

Legenda de prioridade: 🔴 **Indispensável** · 🟠 **Importante** · 🟡 **Desejável**

## Contas e família

| Requisito | Prioridade | User Story |
|---|---|---|
| Cadastro de Usuários | 🔴 Indispensável | Como administrador da família, quero me cadastrar no sistema, para conseguir acessar a plataforma. |
| Login | 🔴 Indispensável | Como usuário do sistema, quero realizar o login, para conseguir acessar o sistema. |
| Criação de família | 🔴 Indispensável | Como responsável pela família, quero criar um grupo familiar, para que os membros possam visualizar e participar das atividades da família. |

## Controle financeiro

| Requisito | Prioridade | User Story |
|---|---|---|
| Controle Financeiro | 🟠 Importante | Como administrador da família, quero registrar as despesas e receitas do meu grupo familiar, para controlar as finanças da família. Como membro da família, quero visualizar o histórico financeiro, para acompanhar os registros financeiros da família. |

## Tarefas domésticas

| Requisito | Prioridade | User Story |
|---|---|---|
| Gerenciamento de Tarefas | 🔴 Indispensável | Como administrador da família, quero gerenciar as tarefas familiares, para organizar as atividades domésticas e distribuir responsabilidades entre os membros. |
| Atualização das Tarefas | 🟡 Desejável | Como membro da família, quero atualizar o status das tarefas, para informar o andamento das atividades. |

## Lista de compras

| Requisito | Prioridade | User Story |
|---|---|---|
| Lista de Compras | 🔴 Indispensável | Como administrador da família, quero criar uma lista de compras, para organizar os produtos que precisam ser adquiridos ou repostos. |
| Controle da Lista | 🟡 Desejável | Como membro da família, quero marcar os itens comprados, para controlar os itens já adquiridos ou repostos. |

## Agenda familiar

| Requisito | Prioridade | User Story |
|---|---|---|
| Agenda Familiar | 🟠 Importante | Como administrador da família, quero registrar compromissos e eventos, para que todos possam consultar a agenda familiar. |
